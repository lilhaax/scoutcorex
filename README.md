# ScoutCoreX

ScoutCoreX is an open-source AI research assistant that helps explore scientific literature using natural language.

The goal is simple: ask a research question, retrieve relevant papers, rank them, and generate evidence-based summaries with clear citations and explanations.

## Current goals

- Natural language paper search
- Paper retrieval from multiple sources
- Semantic ranking
- AI-generated summaries
- Transparent citations
- Explainable paper selection

## Project status

Early development.

The first milestone focuses on building a reliable retrieval pipeline before adding more advanced reasoning features.
